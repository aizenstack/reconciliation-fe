# Data Reconciliation (Frontend)

Vue 3 + TypeScript + Vite + Tailwind CSS + Axios.

**Author:** [Febrian Yosi Pangestu](https://github.com/aizenstack)

## Setup

```bash
cd reconciliation-fe
npm install
```

## Run

```bash
npm run dev
```

Backend: `uvicorn app.main:app --reload --port 8000`
